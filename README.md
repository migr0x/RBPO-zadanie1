# РБПО — задание 1. Подготовка репозитория

Учебный Java-проект для МТУСИ, зачётная книжка: **1БКС24063**.

## Технологии

- Java 21
- Spring Boot 3.5.5
- Maven
- Spring Web
- JUnit 5 и Spring Boot Test

## Реализованные требования

- [x] Создан Java-проект на Spring Boot версии 3.5.5.
- [x] В качестве системы сборки используется Maven (`pom.xml`).
- [x] Создан REST-контроллер с двумя различными GET-эндпоинтами.
- [x] `GET /api/message` выполняет первую функцию: возвращает текст (`text/plain`).
- [x] `GET /api/number` выполняет другую функцию: возвращает число `42` в формате JSON.
- [x] В `application.yml` задано `spring.application.name: "1БКС24063"`.
- [x] Добавлены автоматические тесты для обоих эндпоинтов.

## Требования к окружению

Для запуска необходимы JDK 21 (или совместимая более новая версия) и Apache Maven 3.6.3 или новее.

Проверить установку:

```bash
java -version
mvn -version
```

## Запуск проекта в IntelliJ IDEA

1. Распакуйте архив в отдельную папку.
2. В IntelliJ IDEA выберите **File → Open** и откройте файл `pom.xml` либо корневую папку проекта.
3. Подтвердите импорт Maven-проекта и дождитесь загрузки зависимостей.
4. Откройте `RbpoLab1Application.java` и запустите метод `main` (зелёный треугольник рядом с классом).
5. В консоли должна появиться запись о запуске Spring Boot и встроенного Tomcat на порту `8080`.

## Запуск проекта из терминала

Из корневой папки проекта выполните:

```bash
mvn spring-boot:run
```

После запуска приложение будет доступно на `http://localhost:8080`.

## Проверка эндпоинтов

В браузере или через Postman выполните два GET-запроса:

| Метод | Адрес | Ожидаемый результат |
|---|---|---|
| GET | `http://localhost:8080/api/message` | `Проект РБПО успешно запущен!` |
| GET | `http://localhost:8080/api/number` | `42` |

Примеры проверки через PowerShell:

```powershell
Invoke-RestMethod -Method Get -Uri http://localhost:8080/api/message
Invoke-RestMethod -Method Get -Uri http://localhost:8080/api/number
```

## Запуск автоматических тестов

```bash
mvn test
```

Тесты проверяют HTTP-статус, тип содержимого и тело ответа каждого эндпоинта.

## Публикация на GitHub

1. Создайте на GitHub пустой репозиторий, например `rbpo-lab1-1bks24063` (без автоматического README и `.gitignore`).
2. Откройте терминал в корневой папке этого проекта.
3. Выполните команды, подставив URL созданного репозитория:

```bash
git init
git add .
git commit -m "Create RBPO lab 1 Spring Boot project"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/rbpo-lab1-1bks24063.git
git push -u origin main
```

4. Откройте опубликованный репозиторий и проверьте, что в нём присутствуют `pom.xml`, `src/` и этот `README.md`.
5. Скопируйте ссылку на репозиторий и добавьте её в ответ к заданию в LMS.

> Перед отправкой преподавателю выполните `mvn test` и убедитесь, что сборка завершилась успешно.
